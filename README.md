# Визуализация графа зависимостей

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №15.

## Общее описание

Консольное приложение для анализа зависимостей пакетов Java (Maven).

Реализованные этапы:

1. Чтение и проверка параметров конфигурации из CSV-файла.
2. Получение информации о прямых зависимостях пакета из репозитория Maven.
3. Построение графа зависимостей алгоритмом BFS с рекурсией, ограничением глубины и обработкой циклических зависимостей. Поддержка тестового репозитория.
4. Определение порядка загрузки пакетов с помощью топологической сортировки графа зависимостей.

## Параметры конфигурации

| Параметр | Назначение |
|---|---|
| package | Имя анализируемого пакета |
| repository | URL репозитория или путь к тестовому файлу |
| test_mode | Режим работы с тестовым репозиторием |
| version | Версия пакета |
| output_file | Имя файла изображения графа |
| max_depth | Максимальная глубина анализа зависимостей |

## Описание функций

### main.py

- `read_config()` — чтение конфигурационного файла.
- `validate_repository()` — проверка URL репозитория или пути к тестовому файлу.
- `validate_config()` — проверка параметров конфигурации.
- `create_graph()` — построение графа зависимостей для выбранного режима работы.
- `get_children()` — получение зависимостей пакета из выбранного источника данных.
- `main()` — чтение конфигурации, построение графа и вывод порядка загрузки зависимостей.

### maven.py

- `build_pom_url()` — формирование URL POM-файла.
- `read_properties()` — чтение свойств POM-файла.
- `resolve_version()` — подстановка значения переменной версии.
- `parse_dependencies()` — извлечение прямых зависимостей пакета.
- `get_dependencies()` — получение POM-файла и извлечение зависимостей.

### graph.py

- `read_test_repository()` — чтение тестового репозитория.
- `get_test_dependencies()` — получение зависимостей тестового пакета.
- `get_maven_dependencies()` — получение зависимостей Maven-пакета для построения графа.
- `bfs_recursive()` — рекурсивный обход графа в ширину.
- `build_graph()` — построение графа зависимостей.

### loading.py

- `visit()` — рекурсивная обработка пакета и его зависимостей с обнаружением циклов.
- `get_loading_order()` — определение порядка загрузки пакетов.

## Запуск программы

Для работы программы необходим Python 3 с Python Launcher. Дополнительные библиотеки и сборка не требуются.

Для работы с реальным репозиторием Maven необходимо подключение к интернету.

Команда запуска:

    py -3 -m src.main

Запуск с помощью скрипта:

    .\run.bat

## Тестирование

Команда запуска автоматических тестов:

    py -3 -m unittest discover -s tests -v

Проверяемые случаи:

- Корректность параметров конфигурации.
- Обработка некорректных параметров конфигурации.
- Формирование URL POM-файла.
- Получение прямых зависимостей.
- Подстановка переменных версий.
- Построение графа зависимостей.
- Обработка циклических зависимостей.
- Ограничение глубины анализа.
- Обработка пакетов без зависимостей.
- Определение порядка загрузки пакетов.
- Обработка общих зависимостей.

## Пример работы в тестовом режиме

Содержимое config.csv:

    package,F
    repository,test_repository.json
    test_mode,true
    version,1.0
    output_file,graph.svg
    max_depth,3

Содержимое test_repository.json:

    {
        "A": ["B", "C"],
        "B": ["D"],
        "C": ["D"],
        "D": ["A", "E"],
        "E": [],
        "F": ["G", "H"],
        "G": ["I"],
        "H": ["I"],
        "I": []
    }

Ожидаемый результат:

    Порядок загрузки зависимостей:
    1. I
    2. G
    3. H
    4. F

## Особенности реализации

При построении графа используется алгоритм BFS с рекурсией. Анализ зависимостей выполняется с учётом максимальной глубины.

Порядок загрузки определяется с помощью топологической сортировки. Каждый пакет добавляется в итоговый список после обработки его зависимостей. Повторное добавление пакетов исключено.

При обнаружении циклической зависимости во время определения порядка загрузки программа выводит сообщение об ошибке.

В режиме Maven учитываются непосредственно объявленные зависимости с областями compile и runtime. Поддерживается подстановка переменных версий из текущего POM-файла. Наследуемые версии не поддерживаются.
