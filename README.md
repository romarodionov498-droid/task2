# Визуализация графа зависимостей

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №15.

## Общее описание

Консольное приложение для анализа зависимостей пакетов Java (Maven).

Этап 1 — чтение и проверка параметров конфигурации из CSV-файла.

Этап 2 — получение POM-файла из репозитория Maven, извлечение и вывод прямых зависимостей пакета.

## Параметры конфигурации

| Параметр | Назначение |
|---|---|
| package | Имя анализируемого пакета |
| repository | URL репозитория или путь к тестовому файлу |
| test_mode | Режим работы с тестовым репозиторием |
| version | Версия пакета |
| output_file | Имя файла изображения графа |
| max_depth | Максимальная глубина анализа зависимостей |

## Описание функций

### main.py

- `read_config()` — чтение конфигурационного файла.
- `validate_repository()` — проверка URL или пути к файлу.
- `validate_config()` — проверка параметров конфигурации.
- `main()` — чтение конфигурации, получение и вывод зависимостей.

### maven.py

- `build_pom_url()` — формирование URL POM-файла.
- `read_properties()` — чтение свойств POM-файла.
- `resolve_version()` — подстановка значения переменной версии.
- `parse_dependencies()` — извлечение прямых зависимостей.
- `get_dependencies()` — получение POM-файла и извлечение зависимостей.

## Запуск

Для работы программы необходим Python 3 с Python Launcher и подключение к интернету. Дополнительные библиотеки и сборка не требуются.

Команда запуска:

    py -3 -m src.main

Запуск с помощью скрипта:

    .\run.bat

## Тестирование

Команда запуска тестов:

    py -3 -m unittest discover -s tests -v

## Пример использования

Содержимое config.csv:

    package,org.apache.commons:commons-text
    repository,https://repo.maven.apache.org/maven2
    test_mode,false
    version,1.12.0
    output_file,graph.svg
    max_depth,3

Фрагмент результата выполнения:

    Пакет: org.apache.commons:commons-text
    Версия: 1.12.0
    Прямые зависимости:
    org.apache.commons:commons-lang3 — 3.14.0 (compile)

Программа выводит зависимости, непосредственно объявленные в POM-файле, включая тестовые зависимости.

Поддерживается подстановка переменных версий из раздела properties текущего POM-файла. Наследуемые версии пока не разрешаются.

При некорректных параметрах или ошибках получения данных программа выводит сообщение об ошибке.
