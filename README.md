# Визуализация графа зависимостей

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №15.

## Общее описание

Консольное приложение для анализа зависимостей пакетов Java (Maven).

Этап 1 — чтение и проверка параметров конфигурации из CSV-файла.

Этап 2 — получение POM-файла и извлечение прямых зависимостей пакета.

Этап 3 — построение графа зависимостей алгоритмом BFS с рекурсией, ограничением глубины и обработкой циклов. Поддерживается тестовый репозиторий.

## Параметры конфигурации

| Параметр | Назначение |
|---|---|
| package | Имя анализируемого пакета |
| repository | URL репозитория или путь к тестовому файлу |
| test_mode | Режим работы с тестовым репозиторием |
| version | Версия пакета |
| output_file | Имя файла изображения графа |
| max_depth | Максимальная глубина анализа зависимостей |

## Описание функций

### main.py

- `read_config()` — чтение конфигурационного файла.
- `validate_repository()` — проверка URL или пути к файлу.
- `validate_config()` — проверка параметров конфигурации.
- `create_graph()` — построение графа для выбранного режима.
- `main()` — чтение конфигурации, построение и вывод графа.

### maven.py

- `build_pom_url()` — формирование URL POM-файла.
- `read_properties()` — чтение свойств POM-файла.
- `resolve_version()` — подстановка значения переменной версии.
- `parse_dependencies()` — извлечение прямых зависимостей.
- `get_dependencies()` — получение POM-файла и извлечение зависимостей.

### graph.py

- `read_test_repository()` — чтение тестового репозитория.
- `get_test_dependencies()` — получение зависимостей тестового пакета.
- `get_maven_dependencies()` — получение зависимостей Maven-пакета для построения графа.
- `bfs_recursive()` — рекурсивный обход графа в ширину.
- `build_graph()` — создание графа зависимостей.

Вложенные функции `get_children()` получают зависимости пакета из выбранного источника данных.

## Запуск

Для работы программы необходим Python 3 с Python Launcher. Дополнительные библиотеки и сборка не требуются.

Для работы с Maven необходимо подключение к интернету.

Команда запуска:

    py -3 -m src.main

Запуск с помощью скрипта:

    .\run.bat

## Тестирование

Команда запуска тестов:

    py -3 -m unittest discover -s tests -v

## Пример использования

Содержимое config.csv:

    package,A
    repository,test_repository.json
    test_mode,true
    version,1.0
    output_file,graph.svg
    max_depth,3

Содержимое test_repository.json:

    {
        "A": ["B", "C"],
        "B": ["D"],
        "C": ["D"],
        "D": ["A", "E"],
        "E": []
    }

Результат выполнения:

    Граф зависимостей:
    A: [B, C]
    B: [D]
    C: [D]
    D: [A, E]
    E: []

При построении графа учитывается максимальная глубина. Повторный обход уже обнаруженных пакетов не выполняется. Связи циклических зависимостей сохраняются.

В режиме Maven анализируются непосредственно объявленные зависимости с областями compile и runtime. Поддерживается подстановка переменных версий из текущего POM-файла. Наследуемые версии пока не разрешаются. Если версия необходимой зависимости не определена, программа сообщает об ошибке.

При некорректных параметрах или ошибках получения данных программа выводит сообщение об ошибке.
