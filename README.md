# Визуализация графа зависимостей

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №15.

## Общее описание

Этап 1. Минимальный прототип с конфигурацией.

Консольное приложение считывает параметры из конфигурационного файла CSV, проверяет их корректность и выводит в формате ключ-значение.

## Параметры конфигурации

| Параметр | Назначение |
|---|---|
| package | Имя анализируемого пакета |
| repository | URL репозитория или путь к тестовому файлу |
| test_mode | Режим работы с тестовым репозиторием |
| version | Версия пакета |
| output_file | Имя файла изображения графа |
| max_depth | Максимальная глубина анализа зависимостей |

## Описание функций

- `read_config()` — чтение конфигурационного файла.
- `validate_repository()` — проверка URL или пути к файлу.
- `validate_config()` — проверка параметров конфигурации.
- `main()` — чтение, проверка и вывод параметров.

## Запуск

Для работы программы необходим Python 3. Дополнительные библиотеки и сборка не требуются.

Команда запуска:

    python src/main.py

Запуск с помощью скрипта:

    .\run.bat

## Тестирование

Команда запуска тестов:

    python -m unittest discover -s tests -v

## Пример использования

Содержимое config.csv:

    package,org.apache.commons:commons-lang3
    repository,https://repo.maven.apache.org/maven2
    test_mode,false
    version,3.14.0
    output_file,graph.svg
    max_depth,3

Результат выполнения:

    package: org.apache.commons:commons-lang3
    repository: https://repo.maven.apache.org/maven2
    test_mode: false
    version: 3.14.0
    output_file: graph.svg
    max_depth: 3

При некорректных параметрах программа выводит сообщение об ошибке.
